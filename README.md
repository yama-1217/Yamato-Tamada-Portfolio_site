# Portfolio Project Guide

このプロジェクトは、アーティスト「玉田大和（Yamato Tamada）」のポートフォリオサイトです。
次回以降もこのプロジェクトをスムーズに閲覧・編集できるように、重要な情報をまとめました。

## 1. 閲覧方法
ブラウザで直接ファイルを開くか、VS Codeの「Live Server」などの拡張機能を使用してください。
- **トップページ**: `index.html`
- **作品一覧**: `works.html`
- **作品詳細**: `work-detail.html`
- **プロフィール**: `about.html`

## 2. 編集・更新方法
### 画像の変更
`README_IMAGES.md` にしたがっておこなってください。`images/` フォルダ内のファイルを置き換えるだけで更新できます。

### テキストの変更
各 `.html` ファイルをテキストエディタで開き、該当するテキスト部分を書き換えて保存してください。

## 4. 主な機能
- **レスポンシブデザイン**: スマートフォンとPCの両方に対応しています。
- **スクロール復元**: 作品詳細から戻った際に、元の閲覧位置を保持します。
- **ダイナミックメニュー**: 画面右上のボタンから全画面メニューが開きます。
